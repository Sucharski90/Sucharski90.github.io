When React wasn't the right fit.

01 / CONSTRAINT
The CMS came first.

We initially explored React, but it did not integrate well with the Structure CMS setup.

02 / SOLUTION
History API + layouts.

I used the History API and conditional layouts so navigation, links, meta tags, and imagery could update dynamically.

Dynamic navigation supported persistent podcast and radio playback while users explored different pages.
